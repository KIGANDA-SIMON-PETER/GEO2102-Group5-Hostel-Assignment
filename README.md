# GEO2102 GROUP 5 – HOSTEL MANAGEMENT ASSIGNMENT

## PROJECT DESCRIPTION

This project is a Java-based hostel management program developed as part of the GEO2102 Computer Applications and Programming coursework.

The program stores and processes hostel information, determines whether each hostel is fully occupied or not fully occupied, calculates the average rental amount, and counts the number of fully occupied and not fully occupied hostels.

## PROGRAM FEATURES

The program:

* Stores hostel information.
* Displays hostel details.
* Determines whether a hostel is fully occupied or not fully occupied.
* Calculates the average rental amount.
* Counts fully occupied hostels.
* Counts not fully occupied hostels.
